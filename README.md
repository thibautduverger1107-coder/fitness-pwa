# Fitness (PWA)

Application personnelle de suivi fitness (nutrition, entraînement, pesée, footing), installable sur mobile et desktop.

## Utilisation

Ouvrir l'URL GitHub Pages du dépôt, puis « Ajouter à l'écran d'accueil » (mobile) ou l'icône d'installation dans la barre d'adresse (desktop/Chrome).

## Stockage des données

Les données sont stockées localement dans le navigateur (`localStorage`), propres à cet appareil et à ce navigateur. Aucune synchronisation entre appareils.

## Limitation connue

L'onglet « Aide » (coach IA) est désactivé : il nécessitait l'accès Claude intégré à l'artefact d'origine, non disponible en version autonome.
